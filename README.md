# Портфолио на Vue 3

Одностраничный сайт-портфолио на **Vue 3 + Vite**. В нём есть главная, страница проектов и контактная форма.

## Запуск

```bash
npm install
npm run dev      # сервер разработки
npm run build    # сборка в dist/
npm run preview  # просмотр собранной версии
```

## Как настроить под себя

- Все тексты: имя, навыки, проекты, соцсети — лежат в `src/data/portfolio.js`.
- Контактная форма отправляет JSON методом POST на адрес из `VITE_CONTACT_ENDPOINT`. Подойдёт, например, [Formspree](https://formspree.io).
  Скопируйте `.env.example` в `.env.local` и вставьте свой адрес. Пока адрес не задан, отправка только имитируется, а сообщение пишется в консоль.
- Роутер работает в hash-режиме, а `base: './'` в конфиге Vite. Поэтому папку `dist/` можно выложить на любой статический хостинг (GitHub Pages, Netlify и т. п.) без дополнительной настройки.

## Возможности Vue в проекте

| Возможность | Где |
|---|---|
| Composition API и `<script setup>` | все компоненты |
| Свои composables | `src/composables/`: `useTypewriter`, `useCountUp`, `useDebounce`, `useLocalStorage`, `useFormValidation`, `useContactForm` |
| Свои директивы | `v-reveal`: появление при прокрутке через IntersectionObserver; `v-tilt`: 3D-наклон карточек за курсором |
| Pinia | `stores/ui.js`: тема и уведомления; `stores/favorites.js`: избранные проекты. Всё сохраняется в localStorage |
| Vue Router | ленивая загрузка страниц, 404, `scrollBehavior`, смена `document.title` |
| `<Transition>` / `<TransitionGroup>` | переходы между страницами; анимация фильтрации карточек (FLIP); уведомления |
| `<KeepAlive>` | страница проектов помнит фильтры и поиск после ухода с неё |
| `<Teleport>` | модальное окно проекта и уведомления рендерятся в `<body>` |
| `defineModel`, `useId`, `defineOptions` | `BaseField.vue` (поле формы с `v-model`), `ProjectModal.vue` |

### Контактная форма

- Валидация при вводе, ошибки показываются после ухода с поля.
- Счётчик символов у сообщения.
- Черновик сохраняется в localStorage и восстанавливается после перезагрузки.
- Скрытое поле-ловушка (honeypot) против спам-ботов.
- Индикатор отправки, экран «Отправлено» и всплывающее уведомление.

### Прочее

- Тёмная и светлая тема. Первый раз тема берётся из настроек системы.
- Индикатор прокрутки вверху страницы, «печатающийся» текст, счётчики с анимацией.
- Адаптивная вёрстка и бургер-меню на телефоне.
- Учитывается настройка `prefers-reduced-motion`.
